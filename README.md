# ticTacGo
## A CLI tic tac toe game, all written in Go!  
_Simply clone the repo and play!_

```
git clone https://github.com/Young-Pancake/ticTacGo
cd ticTacGo
go build .
./ticTacGo
```

## If you don't have Go installed install it here:
### [Go install](https://go.dev/doc/install)

## Features
1. Simple interface 
```
          |       |
      1   |   2   |   3
   _______|_______|_______
          |       |
      4   |   5   |   6
   _______|_______|_______
          |       |
      7   |   8   |   9
          |       |
```
adding the number and entering executes the command,

if the input is invalid it will tell you so.

2. Undo function
   
if you find yourself doing an incorrect move, you can undo it by typing
on of the following: 
1. return
2. back
3. undo
